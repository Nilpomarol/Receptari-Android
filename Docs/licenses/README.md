# Bundled font licences

The three typefaces in `app/src/main/res/font/` are all released under the
SIL Open Font License 1.1. The unmodified licence text for each is kept here.

| File | Typeface | Licence |
|---|---|---|
| `lora_variable.ttf`, `lora_italic_variable.ttf` | Lora | [OFL-Lora.txt](OFL-Lora.txt) |
| `playfair_display_variable.ttf` | Playfair Display | [OFL-PlayfairDisplay.txt](OFL-PlayfairDisplay.txt) |
| `pinyon_script_regular.ttf` | Pinyon Script | [OFL-PinyonScript.txt](OFL-PinyonScript.txt) |

The fonts are embedded unmodified. See ADR-009 for what each one is for.
